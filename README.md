# 🤖 LLM-Powered Data Analysis App

A conversational analytics web app built with **Streamlit**. Upload a CSV file, ask questions in plain English, and get answers and charts generated by an LLM that writes and runs Pandas/Matplotlib code on your data.

## Features

- **Natural-language querying:** ask things like *"Show me a correlation matrix"* or *"What's the average value by month?"*
- **Automatic code generation and execution:** the LLM writes Pandas/Matplotlib/Seaborn code, the app runs it against your DataFrame and renders the output inline.
- **Token-optimized context:** small datasets (100 rows or fewer) are sent in full; larger ones are summarized (shape, columns, dtypes, sample rows, descriptive statistics) to control cost and context size.
- **Multi-turn chat:** conversation history is kept in session state, and the last 3 messages (truncated to 500 characters each) are sent for context.
- **Instant data profiling:** row/column counts, memory usage and missing-value totals shown right after upload.
- **Friendly error handling:** failed code execution shows the generated code and error-specific hints (e.g. missing column, non-numeric plot data).

## How It Works

```
CSV upload ──► Pandas DataFrame ──► Build context (full data or summary)
                                          │
User question ───────────────────────────►│
                                          ▼
                              LLM (Groq, gpt-oss-120b)
                                          │
                                          ▼
                     Answer text + Python code block(s)
                                          │
                                          ▼
              Code executed on the DataFrame ──► Charts / output in chat
```

1. The uploaded CSV is loaded into a DataFrame and stored in `st.session_state`.
2. A system prompt is built with the dataset context and analysis guidelines.
3. The prompt, recent chat history and the user's question are sent to the model.
4. Any ` ```python ` blocks in the reply are executed with `df`, `pd`, `plt`, `sns` available, and resulting figures are displayed and saved to chat history.

## Getting Started

### Prerequisites

- Python 3.9+
- A [Groq API key](https://console.groq.com/)

### Installation

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
pip install -r requirements.txt
```

`requirements.txt`:

```
streamlit
pandas
numpy
matplotlib
seaborn
openai
```

### Configure your API key

Create `.streamlit/secrets.toml` in the project root:

```toml
GROQ_API_KEY = "your_groq_api_key_here"
```

> Never commit this file. Add `.streamlit/secrets.toml` to your `.gitignore`.

### Run the app

```bash
streamlit run app.py
```

Then open the local URL shown in the terminal (usually `http://localhost:8501`).

## Usage

1. Upload a CSV from the sidebar.
2. Check the data preview and basic statistics.
3. Ask a question in the chat box, for example:
   - *What are the main trends in my data?*
   - *Create a bar chart of the top 10 categories*
   - *Are there any outliers in the price column?*
4. Review the explanation and the generated chart.

## Limitations and Security Notes

- **Code execution:** the app runs LLM-generated code with `exec()`. This is fine for local or demo use, but it is **not safe for untrusted or public deployments** without sandboxing (e.g. a restricted subprocess, container, or allow-listed operations).
- **Data privacy:** your data (full or summarized) is sent to the Groq API to generate answers. Do not upload sensitive or confidential files.
- **LLM accuracy:** generated code and answers can be wrong. Verify important results.
- **Context size:** very large or wide CSVs are only represented by a summary, so questions that need row-level detail may be answered less accurately.
- **Input format:** only CSV files are supported.
